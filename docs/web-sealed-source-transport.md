## Trust and ownership

The controls run on pull requests. Candidate execution is restricted to workflow dispatch on protected main, with contents-read permission, no persisted checkout credentials, finite job and step timeouts and a single non-cancelling concurrency group. Raw Git blob IDs are passed through environment variables, not interpolated into shell code. Only the fixed Web repository Git API endpoint is allowed; redirects are refused. Archive entry types, sizes, complete inventory, duplicate names, case collisions, traversal paths and raw hashes are checked before any write. The candidate checkout must have the exact base and a clean tree.

Transport code and policy are retained outside the candidate checkout. The raw candidate cannot replace the intake verifier.
